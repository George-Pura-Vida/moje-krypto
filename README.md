# MOJE KRYPTO — Bitcoin s plánem

Responzivní česká aplikace pro evidenci kryptoměnových transakcí, analýzu, modelování budoucí hodnoty Bitcoinu, plán vlastního bydlení a diverzifikaci.

**Hosting:** PHP 8.1+, PDO SQLite, Apache .htaccess, mail(). Zdrojové kódy nejsou určené pro GitHub Pages; pro ostrý provoz používejte PHP hosting s HTTPS. Přihlašování vychází z aplikace Moje renta a má samostatné uživatelské účty.

**Bezpečnost:** žádná hesla ani SMTP tajemství v repozitáři; data uživatelů ukládejte mimo veřejný document root.

**Modely:** budoucí ceny BTC jsou scénáře, ne předpovědi a nejsou investičním doporučením.
